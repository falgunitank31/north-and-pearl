## QUICK WIN #1: Homepage Title & Meta Description

### Current
```
Title: Personalized Jewelry for Meaningful Moments
Meta: (none — missing)
```

### New (DataForSEO Keyword Optimized)
```
Title: Personalized Jewelry for Women | Custom Name Necklaces & Initial Gifts
Meta: Custom personalized jewelry for meaningful gifts. Shop name necklaces, initial necklaces, birthstone jewelry & charm bracelets. Free US shipping.
```

**Why this works:**
- Includes 4 priority keywords (personalized jewelry, name necklaces, initial, charm bracelets)
- Speaks to buyer intent (gifts, women)
- Meta is 155 characters (optimal for SERP display)
- Matches competitor titles (MyNameNecklace, Onecklace, MadeByMary)

**Implementation (Shopify):**
1. Go to **Online Store → Pages**
2. Click **Homepage**
3. Scroll to **Search engine listing preview**
4. Update **Page title** and **Meta description**
5. **Save**

**Time:** 2 minutes

**Issues:**
- No publish dates visible in SERP
- No author bylines (trust signal missing)
- No updated dates

### Updates Needed

**For each blog post, add:**

```
Title: [Current] + add date context if outdated
Meta: [Add publishedDate and author schema]
Author byline: "By North & Pearl Team" or "By [Name]"
Publish date: Display visibly (e.g., "Published August 10, 2026")
Updated date: "Last updated August 10, 2026"
```

### Schema Markup (JSON-LD) to Add to Blog Posts

```json
{
  "@context": "https://schema.org",
  "@type": "BlogPosting",
  "headline": "Charm Bracelet Gift Guide: Custom & Personalized Styles",
  "description": "Complete guide to charm bracelets for personalized gifts...",
  "image": "https://northandpearl.com/images/charm-bracelet-guide.jpg",
  "datePublished": "2026-08-10",
  "dateModified": "2026-08-10",
  "author": {
    "@type": "Organization",
    "name": "North & Pearl",
    "url": "https://northandpearl.com"
  }
}
```

**Implementation (Shopify):**
1. Go to **Online Store → Blog Posts**
2. Edit each post
3. Add visible publish date in intro text
4. Add schema JSON to post HTML/custom liquid
5. Save

## QUICK WIN #5: FAQPage Schema on Top Collections

### Why FAQPage Schema Matters
- Enables **featured snippets** and "People Also Ask" visibility
- Adds Q&A box to SERP
- DataForSEO shows competitors using FAQ strategy
- +15-25% visibility boost for question-based queries

### Collection: Name Necklaces

**Add FAQ schema (JSON-LD):**

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "What is a custom name necklace?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "A custom name necklace is personalized jewelry where any name or word is engraved or stamped onto the pendant. At North & Pearl, each name necklace is handcrafted in gold, silver, or rose gold and arrives gift-ready."
      }
    },
    {
      "@type": "Question",
      "name": "Are name necklaces good gifts?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Yes. Name necklaces make meaningful gifts for birthdays, anniversaries, Mother's Day, graduations, and any occasion. Personalization makes them unique and memorable. All orders include gift wrapping and free US shipping."
      }
    },
    {
      "@type": "Question",
      "name": "Can I customize the style of my name necklace?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Yes. Choose from script, block, or minimal lettering. Select your metal (gold, silver, rose gold), and add optional charms, birthstones, or coordinates. Each necklace is made-to-order."
      }
    },
    {
      "@type": "Question",
      "name": "How long does personalization take?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Personalization is included at no extra cost. Most orders ship within 5-7 business days. Express shipping available. Check your order confirmation for exact delivery date."
      }
    },
    {
      "@type": "Question",
      "name": "What metals are available?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "We offer 14K gold, sterling silver, and rose gold. All metals are tarnish-resistant and designed for everyday wear. Each necklace is handcrafted and arrives with care instructions."
      }
    }
  ]
}
```
